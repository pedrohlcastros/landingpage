# Assets

Esta pasta contém os recursos visuais da landing page.

## Imagem de Perfil

Adicione sua foto de perfil aqui com o nome `profile.jpg`.

**Especificações recomendadas:**
- Nome do arquivo: `profile.jpg`
- Formato: JPG ou PNG
- Dimensões recomendadas: 800x800px (quadrada)
- Tamanho máximo: 500KB
- Resolução: 72 DPI para web

Enquanto você não adicionar sua foto, será exibido um placeholder cinza com o texto "Sua Foto".
