# Landing Page - Pedro Santos

Landing page profissional para consultoria em mensageria e estratégias de vendas.

## 🚀 Sobre o Projeto

Site institucional desenvolvido para apresentar os serviços de consultoria em mensageria, focado em estratégias de vendas através de WhatsApp e outras plataformas de mensagens.

## 🎨 Paleta de Cores

- **#752C14** - Marrom/Terracota (Primário)
- **#453427** - Marrom Escuro (Secundário)
- **#F0EADD** - Bege Claro (Fundo)
- **#104447** - Verde-azulado Escuro (Destaque)
- **#58ADB2** - Azul Turquesa (Destaque Claro)

## 📁 Estrutura do Projeto

```
landingpage/
├── index.html          # Página principal
├── styles.css          # Estilos CSS
├── script.js           # Interações JavaScript
├── assets/             # Recursos visuais
│   └── profile.jpg     # Foto de perfil (adicionar)
└── README.md           # Este arquivo
```

## 🖼️ Como Adicionar sua Foto

1. Adicione sua foto na pasta `assets/` com o nome `profile.jpg`
2. Dimensões recomendadas: 800x800px (quadrada)
3. Formato: JPG ou PNG
4. Tamanho máximo recomendado: 500KB

## 📝 Como Personalizar

### Atualizar Informações de Contato

No arquivo `index.html`, procure por:

```html
<!-- WhatsApp -->
<a href="https://wa.me/5500000000000" target="_blank">

<!-- E-mail -->
<a href="mailto:contato@pedrosantos.com">
```

Substitua pelos seus dados reais.

### Modificar Cores

Edite as variáveis CSS no arquivo `styles.css`:

```css
:root {
    --color-primary: #752C14;
    --color-secondary: #453427;
    --color-light: #F0EADD;
    --color-accent: #104447;
    --color-accent-light: #58ADB2;
}
```

## 🌐 Como Visualizar

Basta abrir o arquivo `index.html` em qualquer navegador moderno.

Ou, se preferir usar um servidor local:

```bash
# Python 3
python -m http.server 8000

# Node.js (npx)
npx serve
```

Depois acesse: `http://localhost:8000`
